Quickstart

Three commands. Sixty seconds.

⚠️
Before you start, you'll need:
  • ✓ Node 18 or newer — node --version to check
  • ✓ A React app of any flavor — Vite (best) or Next.js / Remix / CRA (via MCP, source-mapping is heuristic)
  • ✓ Claude Code installed and signed in — run claude --version to verify
Missing any of these? The install will succeed but the tool won't do anything useful.
  1. 01 Install
    $ npm i -D redev-cli redev-vite-plugin
  2. 02 Add to vite.config.ts 
    import redev from 'redev-vite-plugin';
plugins: [redev(), react()]
  3. 03 Run — then Cmd+Shift+E in your app
    $ npx redev
Docs

Everything you need

Configure the Vite plugin ▸

The plugin walks your JSX and injects data-redev-file, data-redev-line, and data-redev-component on every element.

Only active in dev — production builds are untouched.

redev({
  // optional overrides
  include: ['**/*.tsx', '**/*.jsx'],
  exclude: ['node_modules/**'],
})
The browser overlay ▸

Cmd+Shift+E toggles the overlay. Hover highlights elements; click selects one.

The selection panel shows the component, file path, line, and current classes. Type a change and hit Submit.

The overlay lives in a Shadow-DOM-safe layer with a high z-index. It never interferes with your app's event handlers.

Drop-box mode (how the agent runs) ▸

Redev is agent-agnostic. When you submit a change, it writes .redev/pending.json at your project root.

You paste the generated claude -p ... command in your terminal. Claude Code reads the pending file, edits your source, and writes .redev/completed.json.

The backend watches for the completed file and reloads your browser. Nothing runs on Redev's servers — everything is local.

MCP integration (any framework) ▸

Register Redev with Claude Code once — then your Claude Code session picks up click-to-edit requests automatically. No shell copy-paste. Works with any React framework (Next.js, Remix, CRA, Vite).

claude mcp add redev -- npx redev-mcp

Then in any Claude Code chat, ask "any pending redev requests?" — Claude reads the pending state, edits your source, and reloads your browser.

Terminal-first CLI ▸

Prefer to stay in your terminal? Run npx redev and get an Ink-powered TUI: element info, prompt input, diff viewer, approval — all keyboard-driven.

The browser overlay is optional. You can select in the browser and drive everything else from the terminal.

Troubleshooting ▸

Overlay doesn't appear? Check the Vite plugin is added and dev server restarted. Look for a green badge bottom-right.

Clicks pick the wrong element? Interactive libraries can wrap children. Hold Alt while clicking to select the parent.

Agent doesn't complete? Confirm claude is on your PATH and you're signed in. Watch .redev/log.md.

CI & team workflow ▸

Every change lands in your git diff. Review, amend, or drop it — the workflow is identical to any hand-written edit.

Add .redev/ to .gitignore. It's a scratch directory.

FAQ

Common questions

Is my code sent anywhere? ▸

No. Redev runs entirely on your machine. Claude Code is invoked as a local subprocess and uses your existing session. There's no Redev cloud.

Does it work with Next.js / Vue / Svelte? ▸

Today: Vite + React only. Next.js adapter is on the roadmap. Vue and Svelte are further out — file an issue if you'd use them.

What does it cost? ▸

Redev is MIT-licensed and free. The only cost is your Claude Code subscription (which you already have if you're reading this).

How is this different from browser devtools? ▸

DevTools changes render in-browser and vanish on refresh. Redev edits your actual source files. Your change survives, ships, and is reviewable in git.

Can it break my code? ▸

Every edit is a normal file change. Nothing runs without you pasting the command. Reject any diff via git checkout --. There's no auto-commit.

Does it work on production sites? ▸

No — dev only, by design. The Vite plugin is inert in production builds.
